# Прогресс разработки Cyber-Bang

## ✅ Спринт 3: Игровой цикл и Базовые действия (ЗАВЕРШЕН)

**Статус:** Завершен на 90%. Базовый игровой цикл полностью работоспособен.

### Что реализовано:
1.  **Полный игровой цикл (Server-side):**
    *   Фазы хода: `UPLOAD` (набор 2 карт), `EXECUTE` (розыгрыш), `PURGE` (сброс до лимита HP).
    *   Автоматическая передача хода следующему живому игроку.
    *   Перемешивание сброса при пустой колоде.
    *   Проверка FIREWALL (Карантин) перед началом хода.

2.  **Боевая система и карты:**
    *   **Bang! (ПИНГ!):** Направленные атаки через Drag-and-Drop. Серверная валидация цели, лимита выстрелов (1/ход), фазы хода.
    *   **Miss! (ФАЙРВОЛЛ):** Механика защиты. Клиент получает событие `incomingAttack`, появляется модальное окно с таймером (10 сек). Урон наносится отложенно (`pendingAttacks`). Если защита сыграна — урон отменяется.
    *   **Stimulant (ПИВО):** Восстановление HP. Ограничение: нельзя использовать, если в игре ≤ 2 живых игроков.
    *   **Смерть и победа:** Раскрытие роли при смерти, очистка карт, проверка условий победы (Админ vs Хакеры/Киберпсих).

3.  **Клиентский интерфейс (GameTable):**
    *   **Круглый стол:** Адаптивное позиционирование игроков по эллипсу (всегда снизу — текущий игрок).
    *   **Drag-and-Drop:** Карты перетаскиваются на игроков (атака) или на стол (постоянные карты/пиво). Визуальная подсветка валидных целей.
    *   **Информативность:** Отображение персонажей (видны всем), ролей (скрыты, кроме Админа и себя), HP, статуса хода.
    *   **Модальные окна:** Окно защиты с таймером обратного отсчета.

4.  **Архитектура и надежность:**
    *   Строгая серверная валидация всех действий (`engine.ts`). Клиент только отправляет намерения.
    *   Система `pendingAttacks` для корректной обработки защиты.
    *   Восстановление состояния игры при переподключении (`REQUEST_STATE`).

### ⚠️ Технические долги и переносы (для Спринта 4):
*   **Дистанция:** Сейчас можно стрелять в любого. Логика расчета расстояния (с учетом выбывших) и проверка оружия перенесены в Спринт 4.
*   **Спасение от смерти:** Механика использования Пива *вне хода* при смертельном уроне пока не реализована (только в свой ход).
*   **Тесты:** Unit-тесты для edge cases не написаны (проводилось ручное тестирование).
